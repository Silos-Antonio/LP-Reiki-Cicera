Landing Page – Cicera Bezerra
Conversão, Performance e Experiência do Usuário

Landing Page institucional desenvolvida para uma terapeuta holística, com foco em posicionamento profissional, autoridade e geração de leads.

O projeto foi construído com mentalidade de produto digital: decisões de UI, UX e implementação técnica foram orientadas por performance, clareza de comunicação e otimização de conversão.

🔗 Deploy:
https://cicera-terapias.netlify.app/

🎯 Problema

A profissional precisava:

Fortalecer presença digital
Transmitir credibilidade e acolhimento
Organizar serviços de forma clara
Conduzir o usuário até o contato com mínima fricção

💡 Solução Desenvolvida

Criação de uma Landing Page:

Estruturada com foco em jornada do usuário
Com hierarquia visual estratégica
Aplicando microinterações para reforçar percepção de qualidade
Otimizada para dispositivos móveis (mobile-first)

🧠 Decisões Técnicas e Estratégicas
1️⃣ Performance First

Uso da Intersection Observer API para controlar animações on scroll, evitando listeners pesados e melhorando eficiência de renderização.

✔ Redução de execução contínua de eventos
✔ Melhor controle de ativação de animações
✔ Experiência mais fluida em dispositivos móveis

2️⃣ Microinterações Orientadas à Conversão

CTA com animação sutil 
Efeito de brilho como reforço visual de ação
Feedback visual nos cards interativos
Objetivo: aumentar engajamento sem poluir a interface.

3️⃣ Arquitetura de Código

JavaScript modularizado por responsabilidade
Separação clara entre estrutura (HTML), estilo (CSS) e comportamento (JS)
Código organizado para fácil manutenção e expansão futura

4️⃣ Mobile-First e Usabilidade

Cards com sistema de expansão no mobile para otimização de espaço
Scroll suave entre seções
Layout responsivo com media queries bem definidas

🛠️ Stack Utilizada

HTML5 – Estrutura semântica

CSS3 – Glassmorphism, animações com @keyframes, Media Queries

JavaScript (Vanilla) – Manipulação de DOM e controle de interatividade

Phosphor Icons

Google Fonts (Lora, Montserrat, Poppins)

📈 Diferenciais Relevantes para Produto

Aplicação prática de princípios de UX e copywriting
Interface emocionalmente alinhada ao público-alvo
Foco em conversão, não apenas estética
Performance consciente (evitando excesso de bibliotecas)
Zero dependência de frameworks externos
