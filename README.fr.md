🌿 Landing Page – Cicera Bezerra
Conversion, Performance et Expérience Utilisateur

Landing Page institutionnelle développée pour une thérapeute holistique, avec un objectif clair : renforcer son positionnement professionnel, améliorer sa crédibilité et générer des prises de contact qualifiées.

Ce projet a été conçu avec une mentalité produit : chaque décision d’UI, d’UX et d’implémentation technique a été guidée par la performance, la clarté du message et l’optimisation de la conversion.

🔗 Déploiement :
https://cicera-terapias.netlify.app/

🎯 Problématique

La professionnelle avait besoin de :

Renforcer sa présence numérique
Inspirer confiance et professionnalisme
Structurer ses services de manière claire
Réduire la friction dans le parcours utilisateur
Faciliter la prise de contact

💡 Solution Mise en Place

Développement d’une Landing Page :

Structurée selon un parcours utilisateur stratégique
Avec une hiérarchie visuelle claire
Intégrant des micro-interactions pour renforcer la perception de qualité
Optimisée en approche mobile-first

🧠 Décisions Techniques et Stratégiques
1️⃣ Performance avant tout

✔ Évite les écouteurs d’événements lourds
✔ Améliore la fluidité de rendu
✔ Optimise l’expérience sur mobile

2️⃣ Micro-interactions orientées conversion

CTA avec animation subtile 
Effet lumineux pour attirer l’attention
Cartes interactives avec expansion dynamique
Objectif : augmenter l’engagement sans compromettre l’élégance visuelle.

3️⃣ Architecture et Organisation du Code

JavaScript structuré par responsabilité
Séparation claire entre structure (HTML), style (CSS) et comportement (JS)
Code maintenable et évolutif

4️⃣ Approche Mobile-First et UX

Système d’expansion des cartes pour optimiser l’espace sur mobile
Scroll fluide entre les sections
Media queries structurées et cohérentes

🛠️ Stack Technique

HTML5 – Structure sémantique

CSS3 – Animations @keyframes, Glassmorphism, Media Queries

JavaScript (Vanilla) – Manipulation du DOM et logique interactive

Phosphor Icons

Google Fonts (Lora, Montserrat, Poppins)

📈 Points Forts du Projet

Application concrète des principes UX et copywriting
Interface alignée avec l’émotion et la cible métier
Focalisation sur la conversion et non uniquement l’esthétique
Performance optimisée (sans frameworks lourds)
Zéro dépendance à des bibliothèques externes
